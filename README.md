# GridCraft

วิเคราะห์ระบบไฟฟ้าด้วย Python — โค้ดประกอบโพสต์ของเพจ **GridCraft**

ทุกโฟลเดอร์คือหนึ่งโพสต์ เปิดอ่าน README ในโฟลเดอร์นั้นได้เลย
โค้ดทุกชุดกดรันบน Google Colab ได้ทันที ไม่ต้องติดตั้งอะไรบนเครื่องตัวเอง

## รายการ

- [post01-datacenter-ramp](post01-datacenter-ramp/) — โหลด Data Center กับ ramp rate
  ทำไม "กี่เมกะวัตต์" อย่างเดียวไม่พอ
- [post02-lv-solar-ev-bess](post02-lv-solar-ev-bess/) — ระบบแรงต่ำ: โซลาร์เที่ยงแรงดันเกิน
  EV หัวค่ำแรงดันตก ปรับ tap แก้ไม่ได้ แบตแก้ได้เพราะย้ายไฟข้ามเวลา
- [post03-gfm-vs-gfl](post03-gfm-vs-gfl/) GFL กับ GFM เมื่อความแข็งของกริดเปลี่ยนไป
  จำลองด้วย DPsim GFL มีปัญหาบนกริดอ่อน GFM มีปัญหาบนกริดแข็ง

## หลักการของโค้ดในรีโปนี้

- ใช้ **ระบบทดสอบสมมติหรือระบบทดสอบมาตรฐาน** เท่านั้น
- ตัวเลขทุกตัวบอกที่มา ค่าไหนเป็นสมมติฐานจะระบุไว้ชัดว่าสมมติ
- โค้ดสั้นพอที่จะอ่านจบในครั้งเดียว และแก้ตัวแปรแล้วลองเองต่อได้
